# Layout test: full-screen vs banded, using Instagram Trial Reels

Same voice, script, captions and animation. **Only the layout differs**:
- **BANDED**: the current trycurio.app template, in `../P*/`.
- **FULL**: full-screen 9:16 with no blurred bands, in this folder.

## The fair way (recommended): post both versions as Trial Reels

Trial Reels go only to people who don't follow you. Instagram shows each one to a test audience, and the result is ready after about 24 hours. Posting both versions as Trial Reels gives them the same kind of audience.

For each video, on its day:
1. **Post the BANDED version as a Trial Reel.** In the reel composer, before sharing, switch on **Trial**. Use the caption from the video's `*-instagram-caption.txt`.
2. **About 1 hour later, post the FULL version as a Trial Reel** with the same caption.
3. **Alternate which goes first.** BANDED first on odd days (P1, P3, P5), FULL first on even days (P2, P4, P6), so posting order doesn't bias the result.
4. **After 72 hours, write down for each version:**
   - Plays
   - Skip rate (Insights → the reel → share of viewers who skip in the first 3 s)
   - Average watch time
   - Shares
5. **Share the winner of each pair to your followers** (Trial Reel → "Share to followers"). Leave the loser as a trial.

**How to call it:** FULL wins if it has more plays and a lower skip rate in **at least 4 of the 6 pairs**. Tie or mixed result: run 4 more pairs.

## The simpler way (less fair)

Post BANDED as a normal reel and FULL as a Trial Reel the same day. Compare FULL's plays with **only the non-follower plays** of the BANDED reel (Insights → Views → Followers / Non-followers), because the normal reel also reaches your followers.

## Notes

- **One clean file per platform.** Don't re-upload a downloaded Instagram file anywhere.
- **YouTube Shorts:** upload the winning layout once per video (test T2, 1 a day). Don't post both versions on YouTube.
- **AI label:** Instagram's Help Center asks for an "AI info" label on a realistic AI voiceover. Decide once and apply it to both versions the same way, so it can't affect the test.
- **Record the results** in `../../curio-growth-research-2026-10-20/` (test T1). That's where the call is written down.
